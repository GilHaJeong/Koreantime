# Koreantime

**한국 사회의 시간 배분과 생활구조 변화** — 자동 확정 스냅샷 공개 화면의 정본 저장소.

색인 주제: `대한민국 여가시간 80% 분석`
기준 계약: 구현 스펙·데이터 계약 v0.2 (중복 정리판)

> 이 저장소의 모든 수치는 **자동 계산 결과**이며 **사람 미검토·외부 검증 전** 상태입니다.
> 어떤 값도 확정된 사회 통계로 인용할 수 없습니다.
> 공개·배포·정본 승격은 수동 승인 항목(M)입니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `data/snapshot/` | 정본 스냅샷 6종. Notion 정본 DB에서 옮겨 온 유일한 기준본 |
| `scripts/verify-snapshot.mjs` | 검증 게이트. 실패 시 종료 코드 1로 빌드를 중단 |
| `scripts/verify-snapshot.test.mjs` | 게이트 자체의 시험 11건 |
| `scripts/build-site.mjs` | 스냅샷 → `assets/snapshot.js` 번들 생성 |
| `scripts/build-fonts.mjs` | 자체 호스팅 서체 서브셋 생성 (빌드 시점에만 네트워크 필요) |
| `scripts/serve.mjs` | 로컬 확인용 정적 서버 |
| `index.html`, `assets/` | 공개 화면 |
| `assets/fonts/` | 자체 호스팅 서체 7개 파일 · SIL OFL 1.1 |

## 실행

```bash
npm run test     # 게이트 시험 11건
npm run verify   # 스냅샷 검증 게이트 28항목
npm run build    # 게이트 통과 뒤에만 번들 생성
npm run fonts    # 서체 서브셋 재생성 (스냅샷 문구가 바뀌었을 때만)
npm run serve    # http://localhost:8080
```

`npm run build`는 게이트를 먼저 돌리고 실패하면 번들을 만들지 않습니다. 순서를 우회하지 마십시오.

`npm run fonts`는 화면과 스냅샷이 쓰는 문자만 추려 서체를 다시 만듭니다.
빌드 시점에만 네트워크가 필요하고, 화면을 여는 시점에는 필요 없습니다.

## 표시 규칙

게이트가 강제하는 규칙입니다. 화면에서 임의로 완화할 수 없습니다.

1. 값 종류가 **미확보**인 지표는 `currentValue`를 `null`로 두고, 근처에서 관측된 수치는 `referenceClue`에만 적는다. 현재값 칸에 올리지 않는다.
2. 미확보 지표는 `referenceClue`가 반드시 있어야 한다. 비워 두면 왜 값이 없는지 설명되지 않는다.
3. **직접값이 한 건도 없는 동안 P01~P04의 현재 판정은 모두 `판정 보류`**로 고정한다.
4. 결측을 `0`·`'-'`·빈 문자열로 대체하지 않는다.
5. 주장은 원문(`originalText`)과 출처(`sourceUrl`)가 모두 있어야 한다.
6. 관심 영역은 9종 열거값만 쓴다(`가족·돌봄` 포함).
7. `meta.disclaimer`에 `자동 계산`과 `사람 미검토`가 모두 들어가야 한다.

## 공개 배포

공개·배포는 자동화 등급 **M(수동 승인 필수)** 항목입니다. 자동으로 켜지지 않습니다.

`.github/workflows/pages.yml` 이 기본 브랜치에 올라오면 다음 순서로 돕니다.

1. 게이트 시험 11건
2. 스냅샷 검증 게이트 28항목
3. 화면 번들 재생성 후 **커밋본과 일치하는지 확인** — 다르면 중단
4. 자체 호스팅 서체 7개가 들어 있는지 확인
5. 런타임 외부 CDN 호출이 남아 있지 않은지 확인
6. 위 다섯이 모두 통과해야 배포

하나라도 실패하면 배포 단계에 도달하지 않습니다.

### 사람이 눌러야 하는 것

워크플로만으로는 배포되지 않습니다. 저장소 **Settings → Pages → Build and deployment →
Source** 를 **GitHub Actions** 로 바꿔야 합니다. 이 토글은 API로 켤 수 없고 저장소
소유자만 바꿀 수 있습니다.

켜기 전에 확인할 것:

- 이 저장소는 **공개**입니다. Pages 를 켜면 화면이 인터넷에 열립니다.
- 화면의 수치는 전부 **사람 미검토·외부 검증 전**입니다.
- 그래서 `index.html` 에 `<meta name="robots" content="noindex">` 를 넣어 두었습니다.
  검색 엔진 색인을 막을 뿐 접근을 막지는 않습니다. 링크를 아는 사람은 볼 수 있습니다.
- 사람 검토가 끝나 정본으로 승격할 때 `noindex` 를 뗄지 따로 결정해야 합니다.

| 기본 테마 | 라이트 기본 | 2026-09-26 |
| 다크 테마 | **미제공.** 라이트 한 벌만 유지 | 2026-09-27 |
| 표기 언어 | 한글 단일 | 2026-09-26 |
| 서체 로딩 | **자체 호스팅.** 런타임에 외부 CDN을 호출하지 않음 | 2026-09-27 |

서체를 자체 호스팅하므로 화면을 여는 사람의 열람 기록이 외부 서체 제공자에게
넘어가지 않습니다. 한글 전체 서브셋은 Noto Serif KR 3굵기만 약 22MB라 담지 않고,
이 화면이 쓰는 문자 598자만 추려 7개 파일 365KB로 줄였습니다.
서브셋에 없는 글자는 시스템 바탕·돋움·고정폭 계열로 대체되며 층위 구분은 유지됩니다.
