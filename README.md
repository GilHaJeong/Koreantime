# Koreantime

**한국 사회의 시간 배분과 생활구조 변화** — 자동 확정 스냅샷 공개 화면의 정본 저장소.

색인 주제: `대한민국 여가시간 80% 분석`
기준 계약: 구현 스펙·데이터 계약 v0.2 (중복 정리판)

> 이 저장소의 모든 수치는 **자동 계산 결과**이며 **사람 미검토·외부 검증 전** 상태입니다.
> 어떤 값도 확정된 사회 통계로 인용할 수 없습니다.
> 공개·배포·정본 승격은 수동 승인 항목(M)입니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `data/snapshot/` | 정본 스냅샷 6종. Notion 정본 DB에서 옮겨 온 유일한 기준본 |
| `scripts/verify-snapshot.mjs` | 검증 게이트. 실패 시 종료 코드 1로 빌드를 중단 |
| `scripts/verify-snapshot.test.mjs` | 게이트 자체의 시험 11건 |
| `scripts/build-site.mjs` | 스냅샷 → `assets/snapshot.js` 번들 생성 |
| `scripts/serve.mjs` | 로컬 확인용 정적 서버 |
| `index.html`, `assets/` | 공개 화면 |

## 실행

```bash
npm run test     # 게이트 시험 11건
npm run verify   # 스냅샷 검증 게이트 28항목
npm run build    # 게이트 통과 뒤에만 번들 생성
npm run serve    # http://localhost:8080
```

`npm run build`는 게이트를 먼저 돌리고 실패하면 번들을 만들지 않습니다. 순서를 우회하지 마십시오.

## 표시 규칙

게이트가 강제하는 규칙입니다. 화면에서 임의로 완화할 수 없습니다.

1. 값 종류가 **미확보**인 지표는 `currentValue`를 `null`로 두고, 근처에서 관측된 수치는 `referenceClue`에만 적는다. 현재값 칸에 올리지 않는다.
2. 미확보 지표는 `referenceClue`가 반드시 있어야 한다. 비워 두면 왜 값이 없는지 설명되지 않는다.
3. **직접값이 한 건도 없는 동안 P01~P04의 현재 판정은 모두 `판정 보류`**로 고정한다.
4. 결측을 `0`·`'-'`·빈 문자열로 대체하지 않는다.
5. 주장은 원문(`originalText`)과 출처(`sourceUrl`)가 모두 있어야 한다.
6. 관심 영역은 9종 열거값만 쓴다(`가족·돌봄` 포함).
7. `meta.disclaimer`에 `자동 계산`과 `사람 미검토`가 모두 들어가야 한다.

## 자료 출처

Notion 정본 DB 4종(관심 벡터 · 조기 신호 지표 · 주장 원장 · 원자료 레지스트리)에서 옮겨 왔습니다.
주장 원장의 원자료 참조는 내부 세션 식별자(`session://…`)이며 공개 인용 가능한 외부 출처가 아닙니다.
외부 출처가 확인된 지표(I07·I11)만 화면에 링크를 답니다.
